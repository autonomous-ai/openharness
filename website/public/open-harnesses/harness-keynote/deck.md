<!-- _class: statement -->
# Every new project starts in an empty folder.

Then an afternoon of setup.

<!--
Think about the last thing you started. A video, a circuit, a game.
You open an empty folder. You install the tools, hunt for the right versions, and explain the job to your agent from scratch.
By the time it all works, the idea has gone cold.
So we asked: what if someone who knows the craft had already done all of that?
-->

<!--

# Videos. Robots. Chips.

If you can describe it, you can make it.

<!--
Here is what you can make today.
Videos, written in React and playing while you watch. Robots, learning to stand and walk in real physics. Chips, from one sentence all the way to a bitstream for a real board.
And more: songs, games, printable parts, molecules, diagrams, and keynotes like this one.
