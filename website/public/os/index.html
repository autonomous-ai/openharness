Goodbye apps.
Hello agents.

Harness is a Linux operating system that boots straight into your agents. No desktop to arrange. No app launcher to navigate. Just the work.

Start with OpenCode. Add Claude Code, Codex or pi. Give each agent a project and work side by side. Build on this computer, connect another one, and open the browser when you need to see the result.
