# Provenance

The structured source, synthetic regional data, OOXML writer and wrapper are
original OpenHarness work licensed under MIT. No real company or audited
financial result is represented.

[LibreOffice](https://www.libreoffice.org) is installed separately and used for
document-to-PDF conversion and workbook recalculation. No LibreOffice code,
binary or fonts are redistributed here. The portable writer requires only Node;
a complete preview requires LibreOffice. Native QA used LibreOfficeDev
26.8.0.0.alpha0 from the isolated Codex runtime; other versions require local
doctor/build checks. The generated workbook was independently checked with a
spreadsheet calculation engine. That QA tool is not a package dependency.
