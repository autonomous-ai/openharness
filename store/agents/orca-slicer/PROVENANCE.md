# Provenance

The wrapper, linear G-code parser, Strata inspector and fluted-vessel SCAD/STL
starter are original OpenHarness work, licensed under the included MIT license.

[OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer) is a separately installed
AGPL-3.0 project derived from PrusaSlicer. No slicer binaries, source code or
printer/material profiles are redistributed in this package. Demo builds load
the named profiles from the user's OrcaSlicer installation and record the resolved
settings in the workspace. Tested with version 2.4.2.

The STL was generated from the included original model.scad using OpenSCAD
2021.01. It is a demonstration model, not a certified manufacturable product.
