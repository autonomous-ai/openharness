# Different briefs, different scores

These are original acceptance fixtures, not a style menu. `compose-examples.mjs` writes only this
examples directory. It demonstrates score construction and actual MIDI input rather than preset
selection. No recordings or melodies are attributed to a real customer.

- `orbit-runner/session.json`: 30-second electronic game title, 128 BPM, 4/4, 312 notes.
- `keepsake/input-melody.mid`: the original waltz input fixture, 3/4 with two tempos.
- `keepsake/session.json`: a 33-second arrangement that retains that imported melody, 92 notes.

In a fresh workspace, copy a chosen session to `piece/session.json`, then build/export it with
the workspace tools. Preserve an existing user's source first. These files can also be opened as
projects in the studio. The source repo's revision scenarios preserve approved parts while
changing one requested part. Technical delivery checks passed; listening review remains pending.
