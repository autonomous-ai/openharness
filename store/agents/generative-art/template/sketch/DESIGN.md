# Night Garden · example brief

Create an independent festival identity with oversized type and original cut-paper flowers.
The festival, artists and dates are fictional input fixtures. This is one authored project, not
a restriction on the studio's visual vocabulary. A different brief should receive its own program.

Deliverables: 1200×1600 poster, 1080×1080 announcement, 1920×800 banner; SVG and PNG, editable
project and portable studio. Text, palette, geometry and an optional logo are editable.

The three layouts were exported and visually reviewed during the rebuild. Square flowers and
foliage were reduced to leave space above the title; wide artwork clears the footer. Typography
uses system fonts. Fonts, production color and any print shop's bleed requirements still need
checking for a real commission. A build does not automatically set a ready verdict.

The revision fixture changes dates/venue while retaining the approved geometry and other controls.
See the repository's `store/tools/experience-tests/revisions.mjs` and `work/AUTHORING-REBUILD.md`.
