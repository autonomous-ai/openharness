# Original visual systems

Night Garden in the template, Canopy Coffee here and A Year of Rain here each have a separately
authored drawing program. They demonstrate changing the visual language, controls, inputs and
output composition for a brief. They are acceptance fixtures, not a menu limiting future projects.

In a fresh workspace, copy an example's `project.json`, `artwork.js` and assets into `sketch/`, then
build/export with the workspace tools. Preserve existing work before replacing its source.

Canopy embeds an original logo fixture and editable product details. It is artwork, not a compliant
packaging dieline. The data atlas consumes pasted `label,value` rows and labels its ring scale and
order; its sample observations are explicitly invented. Use the person's actual data in real work.
All three examples have separately composed portrait, square and wide formats.
