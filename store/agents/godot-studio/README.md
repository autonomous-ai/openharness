# Godot Studio · Lumen

Build a playable Godot game from an idea and test it in the Harness pane. The starter is **Lumen**, a small original light garden: guide a spark to six blooms, dash, pause and begin again. Mouse/touch destinations and keyboard controls work in the browser. All visual art is generated by GDScript.

## Start

Install `autonomous/godot-studio` from the Harness Store, with Godot 4.3+ and matching Web export templates. Tested with Godot 4.4.1. Set `GODOT_BIN` for a custom editor path; `GODOT_WEB_TEMPLATE` can point to its matching single-threaded release ZIP.

```sh
sh "$GODOT_SKILLS/godot/scripts/export-web.sh"
```

Try: “Turn this into a constellation puzzle. Connect blooms in a particular order and give each level a different pattern.”

## The build loop

The helper snapshots project source into fresh staging, imports it, runs `scripts/proof.gd`, requires a fresh passing receipt, and exports the Web preset. A failed proof/export clears ready without replacing the prior game. Logs live in `.harness/export.log`.

Lumen's native proof checks spawn, movement, dash speed, pause, bounds, collecting all blooms, and restart. Headless assertions are distinct from browser proof: the repository's real-browser test plays through all six blooms, pauses, restarts, uses keyboard movement, and repeats a pickup at mobile width. Update both tests when mechanics change.

The export uses the Compatibility renderer, single-threaded WASM and no PWA. The shared viewer keeps the game in an opaque-origin sandbox: no persistent browser storage or service workers. Godot 4.4's known optional PWA callback probe is reported as an offline-installation warning there; all other engine errors remain errors.

For optional interaction/performance checks, install Playwright in the shared viewer or set `PLAYWRIGHT_MODULE`, then run the skill's `perf.mjs` with `HARNESS_WORKSPACE` and `build/web/index.html`. `proof.json` exercises actual game pause/restart through its JavaScript bridge; frame results describe that device/browser, not a universal FPS guarantee.
