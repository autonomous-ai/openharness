# Provenance

Lumen's game logic, drawn geometry, custom export shell, native proof and build
helpers are original MIT-licensed OpenHarness work. There are no external art,
font or sound assets. [Godot](https://godotengine.org) is a separately installed
MIT-licensed game engine. Native QA used Godot 4.4.1 with matching official export
templates. Neither editor nor templates are redistributed in this package.
