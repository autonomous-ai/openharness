# Provenance

The Ripple vessel source, mesh inspector, staged-build helper and instructions are
original MIT-licensed OpenHarness work. [OpenSCAD](https://openscad.org) is a
separately installed GPL-2.0 notation-based CAD application. No OpenSCAD code or
binary is redistributed. Native QA used OpenSCAD 2021.01. The CAD pane is the
separate autonomous/cad-viewer package, which carries its own upstream notices.
