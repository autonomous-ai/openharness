# Provenance

Drawer Grid, Bottle Bench, the retained Ripple fixture, requirement evaluator, mesh inspector,
staged builder, handoff UI, ZIP writer and instructions are original MIT-licensed OpenHarness work.
The ZIP writer and restricted handoff server are adapted from the original Score/FreeCAD wrappers
in this repository; portable bundles include their tool license.

[OpenSCAD](https://openscad.org) is a separately installed GPL-2.0 notation-based CAD application.
No OpenSCAD code or binary is redistributed here. Native QA used OpenSCAD 2021.01. STL and SVG
artifacts are generated from original example sources; Store screenshots capture actual outputs.
No physical printing, material testing, food-safety approval or upstream endorsement is claimed.

The CAD pane is the separate autonomous/cad-viewer package, which carries its own upstream notices.
