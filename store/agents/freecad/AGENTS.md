# FreeCAD

Read the `freecad` skill. The saved design is `part.FCMacro`, a Python macro executed by FreeCADCmd.
Keep design inputs at the top and rebuild after changes. The shared CAD Viewer follows `part.step`.

The Pocket starter exports a two-piece electronics enclosure, a vented lid, an STL mesh and a
FreeCAD document. Geometry is generated by the macro; the exported parameter object records inputs,
not a fully constrained Sketcher feature history.

Use the one-stop build. The macro must export into `HARNESS_BUILD_DIR` (falling back to the current
directory only for manual use). The build reimports and checks the newly written STEP in FreeCAD.
An old export is never proof of a successful new build.

State manufacturing assumptions and inspect the real assembly. Closed, valid solids do not prove
wall thickness, strength, fit or suitability for a particular machine.
