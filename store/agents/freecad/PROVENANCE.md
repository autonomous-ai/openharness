# Provenance

The measured enclosure and bench-bracket fixtures, contract validator, native
validation/export runner, projected drawings, handoff page, portable build tools,
loopback download server and instructions are original MIT-licensed OpenHarness
work. The fixtures use synthetic dimensions, not proprietary product data.
[FreeCAD](https://freecad.org) is a
separately installed LGPL-2.1-or-later CAD application; no FreeCAD binary or source
is redistributed. Native QA used FreeCAD 1.1.3. The CAD pane is the separate
autonomous/cad-viewer package, which carries its own upstream notices.
