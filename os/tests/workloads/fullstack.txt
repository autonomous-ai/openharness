Act as a full-stack programmer on Programmer OS. Build a small local issue tracker called Patchboard using Node.js 22, the npm package fastify, and built-in node:sqlite. Install Fastify into this project with npm (do not install anything globally). Serve a responsive keyboard-accessible plain HTML/CSS/JS frontend and a REST API for creating, listing, updating status and deleting issues. Each issue has a title, body, status (open/in_progress/done), and created time. Bind to 127.0.0.1 on configurable PORT default 18882. Store data in a SQLite file configurable by DB_PATH, use parameterized statements, validate inputs, return 400 for bad requests and 404 for missing IDs. Include search and status filter in the frontend and a way to add an issue without using the mouse. Write meaningful Node built-in tests using Fastify inject and a temporary database: CRUD, invalid input, missing IDs, persistence across server close/reopen, and that HTML and assets are served. Add npm test and npm start scripts, run tests, fix failures. Keep dependencies minimal and do not use a bundler, framework frontend or external CDN. Include a concise README. Do the work now without questions or subagents.
API contract: GET /api/issues returns an array of issue objects; POST /api/issues accepts {title,body} and returns a created object with an id and status=open; PATCH /api/issues/:id accepts {status}; DELETE /api/issues/:id deletes it. The frontend uses id=issue-title and id=issue-body for input fields and id=create-issue for the submit button.
