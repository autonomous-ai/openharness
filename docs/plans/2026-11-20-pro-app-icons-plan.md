**Goal:** `pod_app_style(app_id)` in the Pro firmware returns each app's official icon at 72 and 44 px and a two-colour card gradient that white ink reads on at 4.5:1 or better, baked from `.github/assets/apps/<id>.png` by a committed generator, or `NULL` for an app with no icon.

## Decided here, where the spec left it to the builder

- **RGB565.** Encode truncates (`(r>>3)<<11 | (g>>2)<<5 | b>>3`, as `pod_gen_logos.py`); decode replicates the high bits (`r5<<3 | r5>>2`, `g6<<2 | g6>>4`). With this pair the rule reproduces the spec's prototype exactly: VS Code `#1F9CF0` → `#1879BD` 4.66:1, Claude `#D97656` → `#AD5D42` 4.75:1; a sweep of every channel in steps of 17 has no colour failing 4.5:1 at either end.
- **Darkening:** `k` from 100 down to 0, top = encode565(`round(c * k / 100)` per channel), the first `k` whose decoded top gives white ≥ 4.5:1 (k = 0 is black, so it ends). Bottom = encode565(decode565(top) per channel `// 2`).
- **Contrast:** WCAG relative luminance (sRGB linearised, 0.2126/0.7152/0.0722); white's contrast = 1.05 / (L + 0.05).
- **Saturation and value** from 8-bit channels: `mx, mn = max, min`; `S = (mx - mn) / mx` (0 when `mx` is 0), `V = mx / 255` (HSV's own). **Luma** for the dark mark: `0.2126 R + 0.7152 G + 0.0722 B` on 8-bit values (the coefficients `pod_gen_logos.py` `luma` uses). "Most frequent exact colour" is `Counter.most_common(1)` over pixels in row-major order (ties: first seen).
- **"Darkened no further than needed"** reads with the lift: `card_top` is encode565(base), or `contrast < 5.0`, where base is the measured colour, or the charcoal when the measured colour is near-black.
- **The `--check` bullet of the spec's tests** is run by `test/run.sh` (PM decision 4), not again inside `test_app_icons.py`; the test proves the mode itself on synthetic art.
- **Generated layout** (the tests parse it): per app, in `APPS` order, with `cid` = the id with `-` → `_`:
  - `// <id>: measured #RRGGBB, top #RRGGBB <c>:1, bottom #RRGGBB <c>:1` (top and bottom decoded; contrast to 2 decimals);
  - `static const uint16_t a_<cid>_<s>_px[<s*s>] = {…};`, `static const uint8_t a_<cid>_<s>_a[<s*s>] = {…};`, `static const pod_app_icon_t a_<cid>_<s> = {a_<cid>_<s>_px, a_<cid>_<s>_a, <s>};` for s = 72 then 44;
  - one table `static const struct { const char *id; pod_app_style_t style; } rows[] = {` with rows `    {"<id>", {&a_<cid>_72, &a_<cid>_44, 0xHHHH, 0xHHHH}},` (`%04X`), then `pod_app_style` (NULL guard, linear `strcmp`).
- **README format** (the tests parse it): a table with one row per PNG whose first cell is `` `<id>.png` ``, and a section `## Left out` with one line per app id without art: `` - `<id>`: <reason> ``.
- **Metadata strip:** each PNG is rebuilt with `Image.frombytes("RGBA", size, im.convert("RGBA").tobytes())` and saved with no `pnginfo` or `icc_profile`, so no ICC profile or text chunk from `sips` or upstream survives. Pixel values are kept as `sips` wrote them (what the colour prototype measured).
- **Repo icons** are read by Pillow from the largest official raster: a PNG, or the repo's `.icns` when its PNGs are smaller (Pillow's ICNS reader, largest size). A source larger than 512 px is reduced to 512 with LANCZOS.

## Review Focus

1. **The wrong ChatGPT file, or the right one misnamed.** `app.icns` is Codex's icon; a `chatgpt.png` would be silently skipped. A PNG whose name is not in `APPS` stops the generator; the mockup's ChatGPT colour (±8) catches the wrong icon. Tests: Task 2 `test_unknown_art_is_refused`, Task 3 `test_mockup_five`.
2. **The macOS drop shadow:** grey haze around the tile on a coloured card, or the shadow's pixels counted in the colour. Tests: Task 2 `test_shadow_is_cleared_and_cropped`, `test_shadow_is_not_measured`.
3. **A colour that passes in 8 bits but not after RGB565**, or a bottom that rounds below 4.5:1. Test: Task 2 `test_every_colour_reads` (the sweep).
4. **The hyphenated id `terminal-app`:** a valid C name in the arrays, found by its real id in the lookup. Tests: Task 2 `test_render_compiles_and_looks_up`, Task 3 `test_lookup`.
5. **Art and README drifting apart:** a PNG with no README row, or an app neither baked nor listed as left out. Test: Task 3 `test_rows_match_art_and_readme`.
