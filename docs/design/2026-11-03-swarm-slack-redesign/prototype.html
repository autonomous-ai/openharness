Swarm Mobile, modeled on Slack · prototype

Built from feat/mobile-ios-android @ 90d2ce56d, following the article Re-designing Slack on Mobile. Every phone is tappable: bottom tabs, tiles, rows, avatar, Approve. The data is sample data (project names come from the real screen). The terminal is unchanged.

Problems

  1. Two cards (While you were away, Threads) take up ~⅓ of the screen before the first project.
  2. Project rows have 2 lines; line 2, "7 humans", is identical on every row.
  3. Almost every row has an unread dot, so the dot no longer tells you anything.
  4. Things that need you live in 6 places: the Home card, Activity, Work, Team, Status, the Buddy chat.
  5. Swarm has no Search; Harness is reachable only through 4 "Open terminal" menu items; You takes up a whole tab.

Biggest problem: open the app and, within 3 seconds, you cannot see "what needs me", because everything has the same visual weight.

What the Slack article says (short version)

  • People open the app 15–20 times a day, for 20–30 seconds each time. Goal: get more done per visit, not make visits longer.
  • The tab bar went from 5 tabs to 3. Tabs must have labels: the unlabeled version was dropped because it was confusing and poor for accessibility.
  • A row of tiles on Home for unreads and secondary surfaces (Threads, Later, Huddles…).
  • The overlapping "Jump to" and Search tab were merged into one Search, opened by pulling down; swipe sideways to change the result kind.
  • Activity is one feed for every priority item (threads, mentions, alerts, invitations), so there is less jumping between tabs.
  • Each tab has a filter, opened as a bottom sheet (on Android too). The header collapses on scroll.

Recommendation: A. A fixes exactly the 5 problems in the Current tab: the tile bar gives back ⅓ of the screen, 1-line rows use bold text instead of dots, Activity gathers what needs you in one place, Search and the Agents tile open a way into Harness, and the You tab goes away. Almost every change rearranges screens that already exist; only Search is a new screen.

The cost: You is one more tap away, and Home no longer has pull to refresh (data updates on its own; there is still a button in the filter sheet). Two earlier decisions are reversed: the You tab and the Threads row on Home.
