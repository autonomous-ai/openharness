Why Threads felt hidden

  1. Since 2026-11-04 Threads was only an unlabelled icon in Activity's top bar; Home had no way in.
  2. New replies in a followed thread gave no signal anywhere: SwarmThreadsMerge.unread existed but nothing used it.
  3. A tag inside a thread counts into the project's “@2”, which is read on opening the project, but the reply sits in yesterday's thread: the end of the chat shows nothing new.
  4. Dark theme: “26 replies” used the palette accent #bdcbdc, close to body text, and looked the same read or unread.

Biggest issue: Threads had no name and no signal, so new replies sat unseen until someone went looking.

What Slack does

  • Threads sits at the top of Home; threads with unread replies rise to the top of the list.
  • Activity gathers replies, mentions and invitations; Threads still has its own way in from Home.
  • Reply: tap a message → “Reply in thread”, or type in an existing thread's reply box. The phone already works this way.

Sources: Slack Help: Use threads · slack.design: Re-designing Slack on mobile

What changes (three places)

1 · Home: a “Threads” row
A one-row card between the need-you line and the projects, drawn like a project row (a glyph in place of #). Bright with a dot while a followed thread has unread replies, quiet otherwise. No count: tags already show as “@N” on the project row and in Activity. No tile bar.
2 · Activity: the Threads icon goes
One named way in. Activity's top bar keeps only You.
3 · Chat: “N replies” reads as a link
A real link blue (not the palette accent), faces 20 → 24, and a New pill while a followed thread has unread replies; the whole line is a 44 pt target. Once read it says “Last reply …” as before.
Unchanged
Home's top bar (Swarm, Search, +, You), the need-you line, the projects and “Other projects”, the Threads page, the Thread page, tap a message → “Reply in thread”. “Threads” matches Desktop's sidebar. Desktop does not change.

Try

  • Home → the Threads row (bright, with a dot) → back: the row goes quiet.
  • Home → #openharness (“@2”): the end of the chat shows nothing new; scroll up to “26 replies · New” → open the thread. Back on Home, “@2” is gone.
  • Tap Leo's message → “Reply in thread” opens an empty thread to start.
  • Type in the Reply box and send: the reply count goes up and the thread line updates.
  • Switch to “Before (main)”: Home has no Threads row; the Threads icon sits in Activity's top bar.

How it is built

  • Home's row: the followed threads the server lists as unread (SwarmThreadsMerge.unread), less what this phone has read since. No backend change.
  • New pill: the same source, per thread (SwarmThreads.hasNewReplies): it knows “there is something new”, not how much, so it says “New”.
  • Scope: swarm_page.dart, swarm_home_rows.dart, swarm_activity_page.dart, swarm_thread_line.dart, swarm_conversation_page.dart, swarm_threads.dart, with widget tests.
