Onboarding as shipped

What a person sees the first time they open Harness, from Desktop 1.2.60 and CLI 0.3.68 (released 2026-10-09). A short tour while the computer sets up, then a workspace that already has agents in it, chosen from what the person already uses.

Desktop 1.2.60CLI 0.3.68 PRs #1075, #1077, #1061 The approved design The flow before

Screenshots are from a fresh macOS 26 virtual machine with the published build installed from the website's disk image, unless a caption says otherwise. Claude Code and Codex "signed in" are stand-ins that answer at once; OpenCode, and Claude Code and Codex "not signed in", are the real programs.

1 · The tour while the computer sets up

Seven slides, one quiet line at the bottom with the time left and ▸ Details. Harness opens by itself at the end of the slide on screen once setup and the agent downloads are done; there is no button to press.

The slides

2 · No coding agent yet

OpenCode, Codex and Claude Code are downloaded while the tour runs. The workspace is built behind the tour, so OpenCode is already up with a first task typed in when it hands over. Nothing is sent until the person presses Return.

4 · Uses Claude Code and Codex, with past sessions

Their recent conversations that nothing else is running, newest first by last activity (as ⌘P orders them). A session still open in a terminal or app is left alone.

5 · Has Codex installed, never signed in

Someone who installed an agent but never signed in has not used it yet. Their agent's sign-in alone would send them to a browser with no first result, so OpenCode leads with the task and their agent sits beside it.

6 · People who already use Harness

Unchanged. The tour and the first workspace only happen on a computer that has never had Harness (no ~/.harness/cli). Checked by installing the previous release (1.2.59), using it, then installing this one over it.

What changed for a new person

  • Before (1.2.59): a setup screen with a checklist, then an empty box that said "OpenCode is unavailable. Choose an agent.", and Apple's "install developer tools" dialog over the app.
  • Now: the tour, then agents already open; the first result is one Return away. No dialog.
  • The agent picker no longer shows Installed / Needs sign-in / Installs on start; an agent someone picks that is missing installs in its own pane with one line and a bar.
  • Opened from inside the disk image, Harness offers to move itself to Applications.

Next
