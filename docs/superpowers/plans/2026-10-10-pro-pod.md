# Harness Pro · Pod Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Harness Player 1 on the Harness Pro with Pod: Tabs, Tab, Agent, Recap and Talking screens in
an iPod look on white glass, playing the round dial's own pet scenes.

**Architecture:**
- **Self-contained module.** Pod lives in `main/ui/habitat/pod/`. It is a pure model, a navigation stack,
  one file per screen, and a pet player. Each view builds an `ht_scene_t` and a hit list.
- **New run kinds.** Pod adds its own `pro_kind` values: cell sprite, ring arc and gradient. One line in
  `ht_pro_raster` hands them to `pod_draw_raster`, so the shared renderer is not otherwise touched.
- **Assets.** The dial's generated `pets.c` and 28 px engine marks are copied from `main` by a sync script.
- **Glue.** `ui_habitat.c` feeds the model from the messages it already parses and routes scene and touch
  to Pod under `DEVICE_POD`.
- **The one host change.** The daemon adds `agentIds` to each `swarms` item.

**Tech Stack:** C11 on ESP-IDF 5.5.3 (P4) with the Habitat compositor; host tests with `cc` and Python 3;
TypeScript and vitest for the daemon.

**Spec:** `docs/superpowers/specs/2026-10-10-pro-pod-design.md`

1. **A tab with more agents than panes, or an agent in two tabs.** The diagram shows the first four and a
   "+N", and the agent appears in each tab. → Task 5 `pod_model_test_shared_agent`, Task 7
   `tabs_test_more_than_four`.
2. **The open agent disappears mid-screen.** Its pane closes, or the agent leaves the swarm. Pop to its Tab,
   or to Tabs if the tab is gone, with no stale pointer. → Task 6 `nav_test_agent_vanishes`.
3. **A recording when the user leaves.** ‹, ⏮ or ⏭ while Talking sends `voice.abort` exactly once, and never
   `voice.end`. → Task 6 `nav_test_leave_talk_aborts`, Task 9 touch replay.
4. **An older daemon with no `agentIds`.** The other tabs are drawn as empty panes with a count, and opening
   one still lists what is known (the selected tab's tiles). → Task 5 `pod_model_test_no_agent_ids`.
5. **A recap longer than the model keeps** (more than 8 sentences or 2 KB, with UTF-8 Vietnamese). It is cut
   at a sentence or codepoint boundary with "…", and tapping past the last line wraps to the first.
   → Task 5 `pod_model_test_recap_cut`, Task 8 `recap_test_wraps`.
