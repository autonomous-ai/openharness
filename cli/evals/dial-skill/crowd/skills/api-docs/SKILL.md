---
name: api-docs
description: "Use when documenting an HTTP API endpoint or a public library function: writes the purpose, the parameters with types and defaults, the errors it returns, and one complete request and response example that can be pasted and run."
---

Start from the code, not from memory: read the handler and its validation. Document every parameter, its type, whether it is required and its default. List the error codes and when each happens. End with a working example, checked against a local server, and keep the doc beside the code it describes.
