---
name: i18n-strings
description: "Use when adding or changing user-facing text in an app that ships in several languages: moves strings into the message catalog with stable keys, uses placeholders and plural rules instead of concatenation, and leaves room for languages that run longer."
---

Never build a sentence from fragments; give translators the whole sentence with named placeholders. Use the plural and gender forms of the message format. Keys describe meaning, not position. Check the layout with a pseudo-locale that lengthens every string by a third.
