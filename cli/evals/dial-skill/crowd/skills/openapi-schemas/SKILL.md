---
name: openapi-schemas
description: "Use when an API is described by an OpenAPI document: keeps the schema and the handlers in step, reuses components for shared shapes, marks required fields and formats precisely, and regenerates clients and validators from the schema after each change."
---

Edit the schema in the same change as the handler. Put shared objects in components and reference them. Mark nullable and required fields exactly as the code behaves. Run the schema linter, regenerate typed clients, and add an example for each response.
