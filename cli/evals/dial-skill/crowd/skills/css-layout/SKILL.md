---
name: css-layout
description: "Use when laying out a page or component with CSS: flexbox for one dimension, grid for two, spacing from the design scale, no fixed heights that clip text, and a layout that holds from a 320-pixel phone up to a wide desktop."
---

Start with the narrowest screen and widen. Prefer intrinsic sizing and gap over margins on children. Avoid absolute positioning for layout. Test with long words, long translations and large text settings, and remove styles that no element uses.
