---
name: frontend-accessibility
description: "Use when building or changing user interface: semantic elements, labels for every control, keyboard access and visible focus, color contrast that meets WCAG AA, and text alternatives for images, checked with the browser's accessibility tree and a screen reader on the pages that change."
---

Use buttons for actions and links for navigation. Every input has a label; every icon-only control has an accessible name. Tab through the page and check the order and the focus ring. Check contrast with a tool, not by eye. Announce dynamic changes with live regions.
