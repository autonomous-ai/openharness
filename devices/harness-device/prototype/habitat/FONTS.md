# Fonts

- **Geist Mono Regular**, Vercel, v1.4.2. [Official source](https://github.com/vercel/geist-font). Licensed under the SIL Open Font License 1.1; the license is in [`firmware/fonts/GeistMono-OFL.txt`](../../firmware/fonts/GeistMono-OFL.txt). The firmware generators read that vendored TTF in `firmware/fonts/`.

Firmware atlases are generated by [`gen_habitat_fonts.py`](../../firmware/scripts/gen_habitat_fonts.py) with Pillow 12.2.0. They contain fixed-size 2-bit glyph cells; no font engine runs on the ESP32. The browser and firmware use text characters, not image assets.
