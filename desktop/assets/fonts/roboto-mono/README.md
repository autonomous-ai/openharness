Roboto Mono (variable regular and italic), from
https://github.com/google/fonts/tree/main/ofl/robotomono, downloaded 2026-09-27.
Distributed under the SIL Open Font License; see OFL.txt.

The web renderer needs a bundled monospace face; it cannot use the native
system font families selected by desktop. This asset is shared by terminal
cells, workspace chrome, and dialogs on web.
