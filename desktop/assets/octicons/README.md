# GitHub icons

Original 16px icons from [Primer Octicons](https://github.com/primer/octicons),
retrieved September 28, 2026. Used under the included MIT license.

- `git-pull-request.svg`: Open
- `git-merge.svg`: Merged
- `git-pull-request-closed.svg`: Closed
- `git-pull-request-draft.svg`: Draft
- `mark-github.svg`: GitHub repository chooser (retrieved September 29, 2026)

Source: `https://raw.githubusercontent.com/primer/octicons/main/icons/<name>-16.svg`.
Dart and AppKit load the same vectors and apply the shared state colors.
