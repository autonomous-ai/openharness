# Desktop development

Use [CLAUDE.md](CLAUDE.md) for desktop architecture, build commands, and testing
conventions.

Before adding or changing workspace chrome, welcome controls, dialogs, pickers,
forms, or previews, follow the [terminal workspace design system](design/terminal-workspace.md).
For dialogs in particular,
read and follow the [terminal dialog design system](design/terminal-dialogs.md).
Its core rule is **fixed cells, plain text, one-line selection**. It supersedes
older visual handoff notes for these surfaces.
