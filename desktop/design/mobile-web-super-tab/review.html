Super Tab on mobile web

Phase 1 audit of the current UI at 320, 375, 390 and 1440 px, rendered from the fake-data fixture. No production change was made.

Project list & sidebar (drawer)

On a phone the left tree becomes a 240px drawer over the chat. It shows the tree of projects and a one-line Machines summary, but hides every workgroup and machine detail behind a collapse or a second tap.

Lead chat

The conversation becomes full-width. Long content and toolbars do not adapt: a code block runs off the right edge and the header icon row is cramped.

Workgroup & status

Workgroups are not cards. A workgroup chat shows a thin route note and a truncated header; status and checks live in a modal behind the desktop options menu.

People, agents & machines

The roster becomes a full-width overlay that covers the conversation. It reads reasonably, but there is no bottom sheet, so a user cannot keep watching the chat while choosing an agent.

Empty, read-only & offline

Numbered problems

  1. High Sidebar drawer text truncates project names (e.g. “A Very Long Mobile…”), so a phone user cannot read a long title at all.
  2. Medium Workgroups are hidden behind a collapsed tree; there is no home-screen list to jump into a conversation.
  3. High The Machines group is only a one-line “Offline · 4”. Per-machine status, resources, and “add machine” are unreachable on a phone.
  4. Medium Hover-only affordances (“Collapse Projects”, “Invite people”) do not translate to touch.
  5. High A code block does not wrap: long lines run past the right edge at 320px.
  6. High The header icon row is crammed at 320px and the “Members and machines” button sits at the screen edge, making it hard to reach.
  7. Medium Wide markdown tables/lists render as a block wider than the viewport with no horizontal scroll.
  8. Medium The composer is full-width but its attach/send buttons are ~32px, under the 44px touch target.
  9. Medium The “needs you” banner text is clipped and offers no inline action on a phone.
  10. High A workgroup has no card in the chat; its status, PR and open/stop state are buried in a desktop modal.
  11. Medium The workgroup header (“#2 · Owner decision”) is truncated and the transcript is mostly empty on a phone.
  12. Low Agent rows carry a lot of text (name, engine badge, project) and the right-side status icons are very small.
  13. High No bottom sheet: the roster and machines are full-screen overlays that cover the conversation while you choose an agent.
  14. Medium The empty state and offline error are small centered text with a lot of dead space and no obvious create/retry button.
